## Smallest defensible experiment
- Identify ONE license-safe frozen task set with a known deterministic oracle, exact source hashes, task family grouping and known genuine negative/poison cases. If no valid ground truth exists, `ABSTAIN_NO_REFERENCE`; do not substitute a generative model opinion.
- Freeze independent task groups (not frames, tokens or steps), split, agent access, seeds, platform, memory limits, failure injections, and controlled intervention order.
- Compare paired A (scripted/simple baseline), B (same extra-compute budget), C (Vita DAISY agentic hypothesis + antigentic falsification + verified correction). If model/compute matching is infeasible, mark as descriptive, not causal.
- At least 3 genuinely distinct stochastic seeds for repeatability assessment, with the seed list frozen in advance. Distinguish repeated deterministic replay from independent task-group replication. No across-experiment meta-analysis without estimand/variance compatibility.
- Primary: fraction of task groups whose declared reference output and Merkle-bound result independently recompute. Secondary: false admissibility, abstention, replay fidelity, steps, cost, latency, memory.
- Pre-register MESI, noninferiority margin, expected sample size/power/precision. Report paired differences, intervals and multiplicity correction where appropriate. Three identical seeds do not prove replicability.
