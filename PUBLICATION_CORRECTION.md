# Publication seal correction

Predecessor public commit 969f8975ac54d16236241bd0950005eb9f3d6f62 passed the Golden Route verifier but failed the public-bundle verifier after a clean clone.

Cause: the prepublication payload manifest accidentally included local Python __pycache__/*.pyc files. Git correctly ignored those files, and importing the verifier in a different checkout regenerated bytecode with different embedded paths, so the publication-byte seal was not portable.

Successor action: exclude __pycache__ and *.pyc from the publication payload, regenerate all PublicFileFCOs, recompute the publication Merkle root, rerun gitleaks, and verify from a fresh anonymous clone.

The predecessor commit remains in history as a failed publication attempt.
